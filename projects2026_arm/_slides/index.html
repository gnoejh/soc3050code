SOC3050 — STM32 Lecture Decks

5 decks, 2026 ARM edition. Arrow keys to move, o for an overview, p to print or save as PDF.

STM32 Reference Manual (PDF) — the reference behind every deck, also pinned to the top of each slide.

ST Nucleo-C031C6 on Wokwi — the board every lesson from Part 1 runs on, free in the browser. Its page also lists the peripherals Wokwi does not model, which is worth reading before planning any lab.

Board pin names for diagram.json — every string Wokwi accepts on the board end of a wire, and which MCU pin it reaches. PB0 is not one of them; PB0.1 is. Generated from Wokwi's board file.

Open the course notebook in Colab — a real arm-none-eabi-gcc in the browser, with no toolchain to install. Builds, sections and disassembly; it cannot flash or run a board.
